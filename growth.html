My Journey

我的成長故事

跟著哥哥的腳步，從 Python 到 C++，再到 APCS 市賽佳作。這是我的程式人生最坦誠的記錄。

高中學生 Developer
C++ / Python / AI
01

啟蒙：跟著哥哥的腳步

我的程式之旅，其實是從「跟屁蟲」開始的。看到哥哥在電腦前敲敲打打，螢幕上跑出一行行我看不懂的字，然後神奇的事情就發生了。那時候我覺得寫程式超級酷，就像在施展魔法一樣。

為了解開這個魔法的秘密，國中時我報名了橘子蘋果程式學苑的課程，正式接觸了 Python。還記得第一次成功讓電腦跑出「Hello World」時的興奮，那是一種創造出新東西的純粹快樂。

02

初嘗成果：第一個遊戲

在 Python 課程中，我最驕傲的就是完成了一個猜數字的小遊戲。雖然畫面很簡陋，全都是文字介面，但當我把它拿給家人玩，看到他們為了猜中數字而絞盡腦汁時，我深深感受到了軟體開發的魅力。

「原來我也可以寫出讓人使用的東西。」這個念頭成為了我持續學習的最大動力。

03

挑戰：高中與 C++ 的碰撞

升上高中後，我決定挑戰更底層、更考驗邏輯的 C++。這是一段充滿挫折的日子。從 Python 的動態型別轉到 C++ 的嚴格規範，指標、記憶體管理、複雜的資料結構……每一項都讓我吃足了苦頭。

有無數個夜晚，我盯著 Segmentation Fault 的錯誤訊息發呆，為了找一個 Bug 可以耗上好幾個小時。但每當找出錯誤、看到程式順利跑完測試測資，那種突破瓶頸的成就感，是任何遊戲都比不上的。

04

收穫：APCS 與市賽佳作

努力終究會有回報。在不斷的刷題與實作累積後，我參加了 APCS 檢定，並拿下了 觀念第 4 級、實作第 3 級 的成績。

隨後，我代表學校參加了資訊學科能力競賽，獲得了 市賽佳作。站在頒獎台上的那一刻，我想起了國中那個看著哥哥螢幕發呆的自己。從好奇到熱愛，從模仿到創造，程式設計已經成為我生命中不可或缺的一部分。

「未來的路還很長，不管是 AI、後端開發還是更多未知的領域，我都準備好繼續寫下去了。」
