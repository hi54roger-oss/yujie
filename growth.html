My Journey

我的成長故事

從 Python 啟蒙，到 C++、APCS 4/3、資訊競賽與自主實作，記錄我一步步找到資訊方向的過程。

高中學生｜資訊工程申請
C++ / Algorithms / AI × Backend
01

啟蒙：跟著哥哥的腳步

我的程式之旅，其實是從「跟屁蟲」開始的。看到哥哥在電腦前敲敲打打，螢幕上跑出一行行我看不懂的字，然後神奇的事情就發生了。那時候我覺得寫程式超級酷，就像在施展魔法一樣。

為了解開這個魔法的秘密，國中時我報名了橘子蘋果程式學苑的課程，正式接觸了 Python。還記得第一次成功讓電腦跑出「Hello World」時的興奮，那是一種創造出新東西的純粹快樂。

02

初嘗成果：第一個遊戲

在 Python 課程中，最讓我印象深刻的是完成 Flappy Bird。第一次看到自己寫的程式變成可以操作的遊戲，讓我真正感受到「程式可以把想法做出來」。

「原來我也可以寫出讓人使用的東西。」這個念頭成為了我持續學習的最大動力。

03

挑戰：高中與 C++ 的碰撞

升上高中後，我決定挑戰更底層、更考驗邏輯的 C++。這是一段充滿挫折的日子。從 Python 的動態型別轉到 C++ 的嚴格規範，指標、記憶體管理、複雜的資料結構……每一項都讓我吃足了苦頭。

學習 C++ 後，我開始面對更嚴格的型別、資料結構與除錯問題。每次從錯誤訊息找到原因，再讓程式通過測資，都讓我更習慣用拆解問題的方式處理程式錯誤。

04

收穫：APCS 4/3 與資訊科佳作

持續練習後，我在 APCS 取得 觀念第 4 級、實作第 3 級 的成績。

另外，我也代表學校參加新北市數理及資訊能力競賽，取得 市賽佳作。這些經歷讓我更清楚自己的不足，也讓我確定想繼續往資訊工程、系統實作與 AI × Backend 發展。

「未來的路還很長，不管是 AI、後端開發還是更多未知的領域，我都準備好繼續寫下去了。」
