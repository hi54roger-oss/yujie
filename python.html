Python 遊戲開發初體驗
開啟程式的大門

我第一次接觸程式是在國中，參加了橘子蘋果程式學苑的 Python 程式開發班。在這個課程中，我學會了如何使用 Python 這個簡潔優雅的語言，透過長期的累積與鑽研，製作出了多個 Python 專案。

在課堂中，老師教導我們如何使用 Python 進行程式設計，經過充分的練習與理論深入，我逐漸建立了對程式邏輯的理解。最令人印象深刻的是，我能夠獨立完成一個小遊戲專案，這讓我體會到：程式不只是冰冷的代碼，而是一種創意的表達方式。

這段學習經歷奠定了我對程式的熱愛基礎，也讓我明白持續學習和實踐的重要性。正是這份熱忱，驅使我在之後的日子裡不斷探索更深層的程式技術。
