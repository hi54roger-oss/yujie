技術棧架構

以 C++ 與 DPP 為核心，從 Discord API、事件處理到互動式遊戲，逐步建立完整的 Discord Bot。

C++

使用 C++ 建立指令處理、遊戲邏輯、資料結構與伺服器功能。

DPP Library

使用 DPP 串接 Discord API，實作 Slash Command、Button、Embed 與事件處理。

Discord API & Event System

透過事件驅動架構處理使用者指令、訊息、按鈕互動與遊戲狀態，讓 Bot 能即時回應。

代碼架構亮點

在 C++ 中處理 Discord 機器人需要極高的細緻度。我採用了模組化設計，將核心邏輯與指令實作分離，並利用 DPP 的 Lambda 表達式簡化事件註冊。

  • 高效的 Lambda 事件回調處理
  • 自定義的指令路由選擇器
  • 異步 HTTP 請求與 JSON 解析
